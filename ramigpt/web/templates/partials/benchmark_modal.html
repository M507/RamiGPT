Privilege Escalation Benchmark

Deploys only the selected LPE labs on a remote host via Ansible (sudo, SUID, writable paths, capabilities, Python hijack, NFS exports — see docker/benchmark/misconfigs.md), optionally runs selected tools first (BeRoot, LinEnum + AI), then Full AI until root. Port checks, deploy, verify, and AI runs are limited to checked targets. Timeout covers tools + AI per target.
